# AIStudio

This repository contains a backend service and a frontend App Router app.

## Start Here

1. Open the folder you need.
2. For the marketplace UI, go into [frontend](frontend).
3. For backend work, go into [backend](backend).
4. Read the frontend docs at [frontend/README.md](frontend/README.md) and [frontend/ARCHITECTURE.md](frontend/ARCHITECTURE.md).

## Frontend App

The frontend is a polished enterprise AI capability marketplace built with Next.js.

1. Browse capabilities on the homepage.
2. Search by capability name, description, type, or category.
3. Open a capability to view its detail page.
